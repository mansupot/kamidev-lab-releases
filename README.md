# KamiDev Lab

แอปบันทึกงานรายวันบน Mac (Apple Silicon) — repo นี้เก็บเฉพาะไฟล์ติดตั้งและรายละเอียดการอัปเดต ไม่มีโค้ด

## ติดตั้ง / อัปเดต
- ติดตั้งใหม่: ดาวน์โหลดไฟล์ `.dmg` จาก [release ล่าสุด](https://github.com/mansupot/kamidev-lab-releases/releases/latest)
- อัปเดต: ในแอป ตั้งค่า → ทั่วไป → แอปเดสก์ท็อป → ตรวจอัปเดต (แอปเช็กเองทุก 6 ชั่วโมง)
- ตรวจไฟล์: `SHA256SUMS.txt` ในแต่ละ release

## มีอะไรใหม่ในแต่ละเวอร์ชัน

### 0.8.1 — 2026-10-27

#### วันลา (เมนูใหม่)
- **เมนู "วันลา"** อยู่ในหมวดบันทึกเวลางาน (ย้ายออกมาจากตั้งค่า) · ลงวันลาและตั้งค่าจากปุ่มมุมขวาบนของหน้า
- **ลาเป็นช่วงได้** — เลือกวันเริ่มถึงวันสุดท้าย บันทึกให้เฉพาะวันทำงาน (ข้ามเสาร์–อาทิตย์และวันหยุด) · วันลาที่ติดกันแสดงเป็นแถวเดียว
- **โควตาวันลา** ตั้งเองได้ต่อประเภท เช่น ลาพักร้อน 6 วัน / 6 เดือน หรือ 15 วัน / 1 ปี · เลือกเดือนเริ่มรอบได้ · มีการ์ดสรุปใช้ไป / เหลือ
- ลาเกินโควตา: เลือกได้ว่า "ห้ามลาเกิน" หรือ "ลาเกินได้แต่ต้องใส่หมายเหตุ" (รายการขึ้นป้าย "เกินโควตา")
- **ร่างเมลแจ้งลา** จากเทมเพลตที่ตั้งเอง (ผู้รับ / CC / หัวเรื่อง / เนื้อหา + ใส่งานที่ฝากระหว่างลาได้) · เปิดในโปรแกรมเมลของเครื่อง หรือไฟล์ .eml สำหรับ Outlook พร้อมไฟล์ปฏิทิน · แอปไม่ส่งเมลเอง

#### ไฟล์แนบในการ์ด Jira
- **รูปที่ฝังในรายละเอียด / คอมเมนต์แสดงตรงตำแหน่งเดิม** (เดิมขึ้นแค่ป้าย "เปิดในเว็บ Jira") — กดดูเต็มได้
- **เลขไฟล์แนบ #1 #2 …** ใช้เลขเดียวกันทั้งในข้อความและในรายการไฟล์แนบ · ไฟล์แนบบอกว่าอยู่ในรายละเอียด / คอมเมนต์ของใคร กดแล้วเลื่อนไปที่จุดนั้น
- ตัวดูไฟล์: **เล่นวิดีโอ** (mp4 / mov / webm) และ**ดูไฟล์ข้อความ** (txt / log / json / csv / md / yaml) ในแอปได้

#### โน้ตและคอมเมนต์
- **จดโน้ตแบบ markdown ได้ทั้งโปรแกรม** (โน้ตการ์ด · โน้ตลูกทีม · บันทึก 1:1 · บันทึกการเรียนรู้ · รายละเอียดตอนสร้างการ์ด Jira) — แถบเครื่องมือ + แท็บตัวอย่างแบบช่องคอมเมนต์ Jira · ⌘Enter บันทึก · โน้ตเดิมแสดงเหมือนเดิม
- รายชื่อแท็ก @ ในคอมเมนต์ขึ้นใต้บรรทัดที่กำลังพิมพ์
- **เรียบเรียงด้วย AI** เลือกได้ว่าจะได้ภาษาไทยหรืออังกฤษ (จำค่าที่เลือกล่าสุด)

#### ทั่วไป
- **ตัวบอกกำลังโหลด**: โครงร่างหน้าตาเหมือนเนื้อหาจริงตอนรอข้อมูล (ขึ้นเฉพาะเมื่อรอนาน ไม่กะพริบ) · แถบบาง ๆ ขอบบนตอนเปลี่ยนหน้า / ดึงข้อมูล · ปุ่มที่กำลังทำงานมีวงหมุน · กรอบรอรูปไฟล์แนบ

#### แก้ไข
- หน้าสรุปประจำวัน: **ประชุมวันนี้ขึ้นครบทั้งวัน** (เดิมขึ้นเฉพาะนัดที่เริ่มไปแล้ว)
- แท็ก @ คนที่ชื่อมีวงเล็บเหลี่ยม เช่น "ชื่อ[ชื่อเล่น]" ได้แล้ว (เดิมส่งไปเป็นข้อความแปลก ๆ และคนนั้นไม่ได้แจ้งเตือน)
- กด Esc ตอนรายชื่อแท็ก @ เปิดอยู่ ปิดแค่รายชื่อ (เดิมย่อหน้าต่างการ์ดไปด้วย)
- กด "เรียบเรียงด้วย AI" ซ้ำ เรียบเรียงใหม่จากข้อความต้นฉบับ (เดิมดูเหมือนปุ่มไม่ทำงาน)

### 0.8.0 — 2026-10-26

#### หน้าต่างการ์ด Jira
- **แถบการ์ดด้านล่างแบบ taskbar** — การ์ดที่เปิดอยู่เรียงที่ขอบล่างของหน้าต่าง ไม่ลอยทับปุ่มในหน้าแล้ว · เปิดพร้อมกันได้ 10 ใบ · หลายใบช่องหดสั้นลงเอง
- เปิดครบ 10 ใบแล้วจะขึ้นกล่องบอกให้ปิดใบก่อนหน้าก่อน (ไม่ปิดใบเก่าให้เอง) · ปิดจากในกล่องนั้นได้เลย
- **ลากช่องในแถบเพื่อเรียงลำดับ**ได้ (หรือ Shift + ← / →) · คลิกปุ่มกลางเมาส์ที่ช่อง = ปิด
- **เปลี่ยนคนรับ** — กดที่ "ผู้รับ" แล้วค้นชื่อคนในบอร์ด · ปุ่มลัด "ให้ฉัน" / "ยังไม่มีคนรับ"
- **แก้ Story Points** ในช่องได้เลย
- **ปุ่มคัดลอก** ที่หัวการ์ด: ลิงก์ · เลข + ชื่อการ์ด (วางใน Slack / Teams แล้วกดได้) · เลขการ์ด
- **แท็กคนในคอมเมนต์ (@)** — พิมพ์ @ แล้วเลือกชื่อ Jira จะแจ้งเตือนคนนั้น · หน้าตรวจก่อนส่งบอกว่าใครจะได้แจ้งเตือน
- **โน้ตของฉัน** — แท็บ "คอมเมนต์ | โน้ตของฉัน" + ปุ่มโน้ตที่หัวการ์ด · จดได้ทุกคน เห็นคนเดียว เข้ารหัสในเครื่อง ไม่ส่งเข้า Jira
  (โน้ตการ์ดที่เคยจดในภาพรวมทีมย้ายมาให้อัตโนมัติ)
- ทุกการแก้ใน Jira ยังต้องกดยืนยันก่อนเสมอ

#### แก้ไข
- สถานะชื่อยาว (เช่น WAITING FOR DEPLOY ON SIT) ไม่ล้นทับคอลัมน์อื่นในตาราง และป้ายสถานะในข้อมูลการ์ดแสดงพอดี
