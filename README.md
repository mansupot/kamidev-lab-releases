# KamiDev Lab

แอปบันทึกงานรายวันบน Mac (Apple Silicon) — repo นี้เก็บเฉพาะไฟล์ติดตั้งและรายละเอียดการอัปเดต ไม่มีโค้ด

## ติดตั้ง / อัปเดต
- ติดตั้งใหม่: ดาวน์โหลดไฟล์ `.dmg` จาก [release ล่าสุด](https://github.com/mansupot/kamidev-lab-releases/releases/latest)
- อัปเดต: ในแอป ตั้งค่า → ทั่วไป → แอปเดสก์ท็อป → ตรวจอัปเดต (แอปเช็กเองทุก 6 ชั่วโมง)
- ตรวจไฟล์: `SHA256SUMS.txt` ในแต่ละ release

## มีอะไรใหม่ในแต่ละเวอร์ชัน

### 0.9.2 — 2026-11-06

#### ปรับปรุง
- **ภาพรวมทีม / 1:1: สถานะและคนรับงานเห็นชัดขึ้น** — ป้ายสถานะมีจุดสีและขอบ แยก 4 กลุ่ม: ยังไม่เริ่ม (เทา) · กำลังทำ (น้ำเงิน) · รอ / review / ทดสอบ / deploy เช่น "Waiting for deploy on SIT" (ม่วง) · เสร็จ (เขียว) · คนรับงานเป็นป้ายชื่อสีประจำคน
- **ย่อหน้าต่างการ์ด (Workspace) ไม่เปิดแผงขวาให้แล้ว** — กดที่ว่าง / Esc / ปุ่มย่อ = เก็บการ์ดไว้เฉย ๆ แผงขวาเปิดหรือปิดอยู่ก็คงไว้อย่างนั้น (ดูการ์ดที่ย่อไว้ได้ที่แผงขวา แท็บ "การ์ดที่เปิดอยู่")
- **เปิดการ์ดค้างไว้ได้สูงสุด 20 ใบ** (จากเดิม 10)
- **แปลบันทึกงาน ไทย ↔ อังกฤษ (AI)** — ปุ่ม "แปล" ที่หัวกล่องบันทึกงาน (ทั้งวัน) และไอคอนแปลในแต่ละแถว: ดูต้นฉบับคู่คำแปล แก้คำแปลได้ แล้ว "แทนที่ในบันทึก" หรือ "คัดลอกคำแปล" · ในฟอร์มเพิ่มงานมีปุ่ม "แปลเป็น EN / แปลเป็นไทย" (ย้อนกลับได้) · แปลตรงความหมาย ไม่ย่อ (ต่างจาก "เรียบเรียงด้วย AI") · ไม่แตะ Jira · ต้องใส่ Anthropic API key · ถ้า AI คืนข้อความเดิม แอปถามซ้ำให้อัตโนมัติอีกครั้ง และบอกชัดว่าข้อไหนยังไม่ได้แปล (กด "แปลใหม่" ได้)
- **แถว "เพิ่มด่วน" ดูง่ายขึ้น** — แต่ละปุ่มบอกชื่อ ระยะเวลา ประเภท (สีตามประเภท) และเลขการ์ด · อันที่จดไปแล้ววันนี้มีเครื่องหมายถูก · เลื่อนซ้ายขวาได้เมื่อมีหลายอัน · ลิงก์ "จัดการ" ไปหน้า Template
- **หน้าบันทึกงาน: จัดหน้าใหม่ให้กระชับ** — ตัวเลขสรุป 4 ช่องรวมเป็นแถบเดียวเตี้ย ๆ · ฟอร์มเพิ่มงานอยู่ในกล่องบันทึกงาน (ไม่แยกการ์ด) · ปุ่มงานที่จดบ่อย / "เหมือนวันก่อน" เป็นแถว "เพิ่มด่วน" · แถวรายการเตี้ยลง ("ส่งเวลาแล้ว" เป็นไอคอน) · **AI ร่างบันทึกเป็นหน้าต่าง** เปิดจากปุ่ม "AI ร่าง" ที่หัวกล่องกิจกรรม (มีร่างรอตรวจ = ปุ่มบอกจำนวน "ร่างรอตรวจ n") ไม่กินที่ในหน้าแล้ว
- **สร้างการ์ด Jira ได้เลยจากหน้าบันทึกงาน** — ปุ่ม "สร้างการ์ด" ที่หัวหน้าและหัวกล่องบันทึกงาน ไม่ต้องจดงานก่อน · สร้างเสร็จเปิดฟอร์มเพิ่มงานพร้อมเลขการ์ดใหม่ให้ (ปุ่มสร้างการ์ดจากบันทึกที่ยังไม่มีการ์ดยังอยู่)
- **ภาพรวมทีม: ตาราง "งานรายคน" กระชับขึ้น** — แถวเตี้ยลง ตัวเลข 0 แสดงจาง · เพิ่มคอลัมน์ **SP รวม** (เสร็จ + เหลือ) พร้อมแถบสองสี (เขียว = เสร็จ · ม่วง = เหลือ) · แถวล่างรวมทั้งทีม · ตำแหน่งและปุ่มโน้ตแยกเป็นคอลัมน์ของตัวเอง (จอแคบซ่อนตำแหน่ง)
- **สวิตช์ "Flag" บนการ์ด (Blocked / On hold)** — เปิดที่หัวหน้าต่างการ์ด / หน้าการ์ด เก็บในแอปเท่านั้น ไม่เปลี่ยนอะไรใน Jira · อยู่ในไฟล์ส่งออก / สำรองข้อมูล
  - **Blocked** (ทำต่อไม่ได้ มีอะไรขวาง): สีแดง · บอกได้ว่า "รออะไร / ใคร" · นับวันที่ติด · นับเป็น "ติดอยู่" ในภาพรวมทีม
  - **On hold** (ตั้งใจพักไว้): สีส้ม · เลือก "พักถึงวันที่" ได้ ครบกำหนดแล้วเตือนให้กลับมาดู · ไม่นับว่าติด และไม่นับ "ค้างนาน" · ภาพรวมทีมมีตัวเลข "พักไว้" แยก (กดเพื่อดูรายการ)
  - การ์ดเปลี่ยนสีทุกที่ที่แสดง: เลขการ์ดทั่วแอป · แถวในการ์ด Jira, ภาพรวมทีม, ภาพรวม, สรุปประจำวัน และแถบการ์ด · การ์ดที่เสร็จแล้วไม่นับ
- **ภาพรวมทีม: จัดหน้าใหม่** — ตัวกรองทั้งหมด (บอร์ด · sprint · การ์ดแม่ · คนในทีม · สถานะ) รวมอยู่ในปุ่ม "ตัวกรอง" เปิดเป็นหน้าต่างเดียว มีผลทันที · แถบด้านบนแสดงตัวกรองที่ใช้อยู่เป็นชิป กด × เพื่อเอาออก หรือ "ล้างทั้งหมด" · ปุ่มเฟืองเลือกได้ว่าจะแสดงส่วนไหน (Sprint + burndown · ตัวเลขสรุป · งานรายคน · รายการการ์ด · กล่องติดอยู่ / ค้างนาน / ยังไม่มีคนรับ) · แอปจำตัวกรองและส่วนที่ซ่อนไว้
- **ภาพรวมทีม: ตัวกรองบอร์ด · sprint · การ์ดแม่ (parent)** — เลือกบอร์ดแล้วดูเฉพาะการ์ดของบอร์ดนั้น · เลือก sprint ได้ทั้งที่กำลังเดิน ถัดไป และที่จบแล้ว (สรุป sprint / burndown / งานรายคน ตาม sprint นั้น) · เลือกการ์ดแม่แล้วเห็นความคืบหน้าของลูก ๆ พร้อมสรุปทุกส่วนเฉพาะใต้การ์ดนั้น · สลับรายการเป็น "ตาม parent" ดูเป็นโครงสร้าง tree (การ์ดแม่ → ลูก มีเส้นเชื่อม) ย่อ / ขยายทีละกลุ่มหรือทั้งหมดได้ (← → บนคีย์บอร์ด) และจำว่าย่อกลุ่มไหนไว้ · "เปิดใน Jira" ใช้ตัวกรองเดียวกัน · แอปจำตัวกรองไว้
- **หน้า 1:1: กล่อง "เสร็จแล้ว · 14 วันล่าสุด"** แทนบรรทัดรายชื่อการ์ด — ดูได้ว่าลูกทีมปิดงานอะไรไปบ้าง ใหม่สุดก่อน พร้อมชื่อการ์ด วันที่เสร็จ (วันนี้ / เมื่อวาน / n วันก่อน) SP ประเภท และ sprint · หัวกล่องรวมจำนวนใบ + SP · กด "+ หัวข้อ" เพื่อเพิ่มเป็นหัวข้อค้างคุยไว้ชมผลงานตอนคุย 1:1

#### แก้ไข
- **แท็บ (Workspace) ถูกตัดครึ่ง / แท็บที่เปิดอยู่ไม่โผล่** ตอนมีแท็บเยอะจนล้น — เปิดแอปแล้วเลื่อนไปที่แท็บที่เปิดอยู่เสมอ · เลื่อนแล้วหยุดตรงขอบแท็บพอดี ไม่ค้างครึ่งใบ · ขอบซ้าย/ขวาจางลงเมื่อยังมีแท็บซ่อนอยู่ · ล้อเมาส์เลื่อนแท็บซ้าย-ขวาได้
- **ทุกหน้าจัด layout ตามพื้นที่ที่เหลือจริง** — ตอนเปิดเมนูย่อยและแผงขวาใน Workspace หน้าจะเรียงเป็นคอลัมน์เดียวแทนการบีบ 2 คอลัมน์จนตัวหนังสือขึ้นบรรทัดทีละคำ (สรุปประจำวัน · บันทึกงาน · ปฏิทิน · ภาพรวม · วันลา · ตั้งค่า ฯลฯ) · หน้าต่างกว้างกลับเป็นหลายคอลัมน์เอง
- แผงขวาดันเนื้อหาแทนการลอยทับ (ลอยทับเฉพาะหน้าต่างแคบกว่า 1024 px)
- กระดาษรายงาน Timesheet ย่อให้พอดีพื้นที่ ไม่ต้องเลื่อนซ้ายขวา (พิมพ์ / PDF ขนาดเท่าเดิม)

### 0.9.0 — 2026-11-02

#### Workspace แบบใหม่ (ค่าเริ่มต้นในแอป)
- **หน้าตาแบบ Workspace** — แถบไอคอนเมนูใหญ่ด้านซ้าย (ชี้แล้วเห็นชื่อ) · แผงเมนูย่อยของหมวดที่เลือก · แถบบนมีปุ่มค้นหาและแท็บ
- ซ่อน / แสดงแผงเมนูย่อยด้วย **⌘\\** หรือกดไอคอนหมวดเดิมซ้ำ — แอปจำไว้ให้
- บน Mac **แถบชื่อหน้าต่างรวมเข้ากับแอป** — ปุ่มแดง เหลือง เขียวอยู่ในแถบบน ลากหน้าต่างจากแถบบนได้ (ทุกรูปแบบเมนู)
- อยากได้แบบเดิม: ตั้งค่า › การแสดงผล › รูปแบบเมนู เลือก "เมนูซ้าย" หรือ "Tab bar" ได้เหมือนเดิม
- **แท็บแบบ Obsidian** — เปิดหน้าจากเมนูแล้วได้แท็บใหม่ที่แถบบน (หน้าที่เปิดอยู่แล้ว = กลับไปแท็บเดิม) · แท็บที่เปิดอยู่ต่อเป็นผืนเดียวกับหัวเพจ · คลิกปุ่มกลางเมาส์ = ปิด · ปุ่ม ˅ ดูแท็บทั้งหมด
- **ลากเรียงแท็บแบบ browser** — แท็บที่ลากตามเมาส์ แท็บอื่นเลื่อนหลบให้ ปล่อยแล้วไหลเข้าช่อง · เปิด / ปิด / เรียงแท็บมีการเคลื่อนไหวนุ่ม ๆ (ปิดได้ด้วย "ลดการเคลื่อนไหว" ของ macOS) · คีย์บอร์ด Shift + ← → ก็เรียงได้
- **+ แท็บใหม่**: ค้นหา / เปิดหน้าจากรายการเมนู / เปิดหน้าที่เพิ่งปิด · แอปจำแท็บไว้ เปิดแอปครั้งหน้าแท็บยังอยู่
- **คีย์ลัดแท็บ** (ในแอป): ⌘T แท็บใหม่ · ⌘W ปิดแท็บ (แทนการปิดหน้าต่าง) · ⌘⇧T เปิดแท็บที่ปิดล่าสุด · ⌃Tab / ⌃⇧Tab แท็บถัดไป / ก่อนหน้า · ⌘1–⌘8 แท็บที่ 1–8 · ⌘9 แท็บสุดท้าย
- แท็บเป็นทางลัดไปหน้านั้น ไม่ได้ค้างหน้าไว้ — ข้อความที่พิมพ์ค้างแต่ยังไม่บันทึกจะหายเมื่อสลับแท็บ · เปิดได้ 20 แท็บ (เกินแล้วแท็บซ้ายสุดปิดเอง)
- **บุ๊กมาร์ก** หน้าที่ใช้บ่อย: กดไอคอน 🔖 ขวาสุดของแถบบนเพื่อเก็บหน้านี้ · ปุ่มบุ๊กมาร์กข้างปุ่มค้นหาเปิดรายการ ลากเรียงได้ · **⌥1–⌥9** เปิดบุ๊กมาร์กอันที่ 1–9 เป็นแท็บ (หน้าที่มีแท็บอยู่แล้ว = กลับไปแท็บเดิม) · เก็บได้ 20 หน้า อยู่ในสำรองข้อมูลและไฟล์ส่งออก
- **แผงขวา** (ปุ่มขวาสุดของแถบบน หรือ ⌘⇧\\): **การ์ดที่เปิดอยู่** แทนแถบล่าง — ย่อหน้าต่างการ์ดแล้วการ์ดไปอยู่ที่แผงขวา ลากเรียง / ปิดได้ · **กิจกรรมวันนี้** ดูเร็ว ๆ ว่าทำอะไรไปแล้ว อันไหนจดแล้ว
- **การ์ด Jira เปิดเป็นหน้าต่างลอยหรือแท็บก็ได้** — ปุ่ม "เปิดเป็นแท็บ" ในหน้าต่างการ์ด · ในแท็บการ์ดมีปุ่ม "เปิดเป็นหน้าต่างลอย" · **⌘ + คลิกเลขการ์ด = เปิดอีกแบบ** (⇧ + คลิก = เว็บ Jira) · เลือกแบบที่คลิกปกติได้ที่ ตั้งค่า › การแสดงผล
- **โน้ต** (เมนู "โน้ต" ในหมวดหน้าหลัก) — จด markdown ได้ทั้งเรื่องงานและเรื่องส่วนตัว บันทึกเองทุกครั้งที่พิมพ์ · จัดเป็น**โฟลเดอร์** (ซ้อนได้ ลากโน้ต / โฟลเดอร์ไปวางเพื่อย้าย) · เปิดแต่ละโน้ตเป็นแท็บของตัวเอง
- พิมพ์ **[[ชื่อโน้ต]]** เพื่อลิงก์ไปโน้ตอื่น (ยังไม่มีโน้ตนั้น กดแล้วสร้างให้) · เลขการ์ด เช่น ABC-12 ในโน้ตกดเปิดการ์ดได้ · แผงขวามี **ลิงก์มาที่นี่** (โน้ตไหนลิงก์มาหาโน้ตนี้) และ **สารบัญ** (กดหัวข้อแล้วไปที่บรรทัดนั้น)
- **ค้นหาโน้ต** ได้ทั้งชื่อและเนื้อหา ที่หน้าโน้ตและใน ⌘K · "+ แท็บใหม่" และ ⌘K มี "โน้ตใหม่" · โน้ตอยู่ในสำรองข้อมูลและไฟล์ส่งออกด้วย

- **หน้าต่างตั้งค่าแบบใหม่** — กด **⌘,** หรือไอคอนตั้งค่าที่แถบซ้าย เปิดเป็นหน้าต่าง: หมวดจัดกลุ่ม (ตัวเลือก / การเชื่อมต่อ / เอกสาร) · **ค้นหาการตั้งค่า**ได้ · "เปิดเป็นแท็บ" ถ้าอยากเปิดค้างไว้
- หมวด "ทั่วไป" และ "การแสดงผล" (แยกออกมาเป็นหมวดของตัวเอง) จัดเป็นแถว: ชื่อ + คำอธิบายซ้าย ตัวเลือกขวา · เพิ่มตัวเลือก **"เปิดแท็บเดิมเมื่อเปิดแอป"** (ปิด = เริ่มด้วยแท็บเดียวทุกครั้ง)
- หน้าต่างแอปแคบ (ต่ำกว่า 1200 px) แผงขวาลอยทับเนื้อหาแทนการเบียด · ตัวหนังสือสีจางในเมนู แท็บ และคำแนะนำเข้มขึ้นให้อ่านง่าย (ผ่านเกณฑ์ contrast)

#### ดีไซน์กระจก Liquid Glass (ทดลอง)
- **เปิดได้ที่ ตั้งค่า › การแสดงผล › "ดีไซน์กระจก (ทดลอง)"** — พื้นหลังมีรูปทรงสีนุ่ม ๆ เมนู การ์ด และหน้าต่างเป็นกระจกฝ้า · ใช้ได้ทั้งธีมสว่างและมืด · ปิดไว้เป็นค่าเริ่มต้น
- **ปรับ "ความใส"** ได้ตั้งแต่ฝ้า (อ่านง่าย) ถึงใส (เห็นพื้นหลัง) — ตัวหนังสือยังอ่านได้ชัดทุกระดับ (ผ่านมาตรฐาน contrast 4.5:1)
- **เลือกภาพพื้นหลังได้**: ชุดสีคราม / ซากุระ / มัทฉะ · สีเรียบ · หรือ**รูปของคุณเอง** (JPG / PNG / WebP) — รูปเก็บในเครื่องนี้เท่านั้น และแสดงเต็ม ๆ ไม่มีม่านทับ
- **กระจกแบบ iOS**: Tab bar / แคปซูลการ์ด / เมนู ☰ ใสเกือบหมด มีการหักเหแสงที่ขอบและขอบสะท้อนแสง · การ์ดที่มีตัวหนังสือทึบขึ้นเท่าที่จำเป็นตามสีของพื้นหลัง (พื้นหลังสีเรียบ = ใสที่สุด)
- **แถบ "ความใส" ปรับได้ตั้งแต่ฝ้าจนใสมาก** ทั้งการ์ด หัวเพจ เมนู และหน้าต่าง · ขีดสีเขียวบนแถบบอกจุดที่ตัวหนังสืออ่านได้แน่นอน (ขึ้นกับธีมและภาพพื้นหลัง) — ใสเกินจากนั้นแอปเติมเงาจาง ๆ รอบตัวหนังสือให้
- **ปรับความเบลอของพื้นหลังได้** (ไม่เบลอ – 40 px) — ใช้คู่กับการ์ดใส ๆ จะได้กระจกฝ้าแบบ iOS
- ถ้าตั้ง **"ลดความโปร่งใส"** ใน macOS ไว้ แอปจะใช้พื้นทึบให้เอง · หน้ารายงานสำหรับพิมพ์ / PDF เป็นกระดาษขาวเหมือนเดิม

#### เมนูแบบ Tab bar (ทดลอง)
- **เลือกรูปแบบเมนูได้** ที่ ตั้งค่า › การแสดงผล › "รูปแบบเมนู": Workspace (ค่าเริ่มต้น) · เมนูซ้ายแบบเดิม · หรือ **Tab bar แคปซูลลอยด้านล่าง**
- Tab bar ปักหมุด 5 เมนูแรกตามลำดับในเมนูซ้าย + การแจ้งเตือน · เมนูที่เหลืออยู่ใน **☰ เมนูทั้งหมด** (จัดหมวดเหมือนเดิม มีปุ่มค้นหา ⌘K และล็อก)
- **คีย์ลัด ⌘1–⌘6** ไปที่แต่ละแท็บ · **⌘7** เปิด / ปิดเมนูทั้งหมด · ตัวเลขแดงบอกงานรอ (เมนูที่อยู่ใน ☰ รวมตัวเลขไว้ที่ปุ่ม ☰)
- ใช้ Tab bar แล้ว **การ์ด Jira ที่ย่อไว้อยู่ในแคปซูลเล็ก ๆ ข้าง Tab bar** แทนแถบล่าง — แสดง 3 ใบล่าสุด (เลขการ์ด · × ขึ้นตอนชี้) ที่เหลือกด **+N** เปิดรายการทั้งหมดพร้อมชื่อการ์ด ลากเรียง / ปิดได้ · เปิดได้ 10 ใบเหมือนเดิม
- **จัดหน้าใหม่สำหรับ Tab bar**: เนื้อหาอยู่กลางจอ ไม่ยืดเต็มจอกว้าง · หัวเพจเป็นแคปซูลลอยพร้อมโลโก้แอป (กด = ภาพรวม) · หน้ารายการ เช่นการแจ้งเตือน / วันลา แคบลงอ่านง่าย · ปฏิทิน / รายงานกว้างกว่า

#### หน้าต่างการ์ด Jira
- เปิดดีไซน์กระจกแล้ว หน้าต่างการ์ดเป็นกระจกขอบโค้ง เห็นงานด้านหลังจาง ๆ

### 0.8.1 — 2026-10-27

#### วันลา (เมนูใหม่)
- **เมนู "วันลา"** อยู่ในหมวดบันทึกเวลางาน (ย้ายออกมาจากตั้งค่า) · ลงวันลาและตั้งค่าจากปุ่มมุมขวาบนของหน้า
- **ลาเป็นช่วงได้** — เลือกวันเริ่มถึงวันสุดท้าย บันทึกให้เฉพาะวันทำงาน (ข้ามเสาร์–อาทิตย์และวันหยุด) · วันลาที่ติดกันแสดงเป็นแถวเดียว
- **โควตาวันลา** ตั้งเองได้ต่อประเภท เช่น ลาพักร้อน 6 วัน / 6 เดือน หรือ 15 วัน / 1 ปี · เลือกเดือนเริ่มรอบได้ · มีการ์ดสรุปใช้ไป / เหลือ
- ลาเกินโควตา: เลือกได้ว่า "ห้ามลาเกิน" หรือ "ลาเกินได้แต่ต้องใส่หมายเหตุ" (รายการขึ้นป้าย "เกินโควตา")
- **ร่างเมลแจ้งลา** จากเทมเพลตที่ตั้งเอง (ผู้รับ / CC / หัวเรื่อง / เนื้อหา + ใส่งานที่ฝากระหว่างลาได้) · เปิดในโปรแกรมเมลของเครื่อง หรือไฟล์ .eml สำหรับ Outlook พร้อมไฟล์ปฏิทิน · แอปไม่ส่งเมลเอง

#### ไฟล์แนบในการ์ด Jira
- **รูปที่ฝังในรายละเอียด / คอมเมนต์แสดงตรงตำแหน่งเดิม** (เดิมขึ้นแค่ป้าย "เปิดในเว็บ Jira") — กดดูเต็มได้
- **เลขไฟล์แนบ #1 #2 …** ใช้เลขเดียวกันทั้งในข้อความและในรายการไฟล์แนบ · ไฟล์แนบบอกว่าอยู่ในรายละเอียด / คอมเมนต์ของใคร กดแล้วเลื่อนไปที่จุดนั้น
- ตัวดูไฟล์: **เล่นวิดีโอ** (mp4 / mov / webm) และ**ดูไฟล์ข้อความ** (txt / log / json / csv / md / yaml) ในแอปได้

#### โน้ตและคอมเมนต์
- **จดโน้ตแบบ markdown ได้ทั้งโปรแกรม** (โน้ตการ์ด · โน้ตลูกทีม · บันทึก 1:1 · บันทึกการเรียนรู้ · รายละเอียดตอนสร้างการ์ด Jira) — แถบเครื่องมือ + แท็บตัวอย่างแบบช่องคอมเมนต์ Jira · ⌘Enter บันทึก · โน้ตเดิมแสดงเหมือนเดิม
